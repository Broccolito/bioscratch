# Bioscratch 0.6.0

Bioscratch 0.6.0 adds a notes browser for ordinary folders to the macOS app,
alongside safer closing, faster tab navigation, and a visible Export menu.
Files remain plain Markdown and tags use standard YAML front matter.

## Notes browser for macOS

- Open a folder with **Shift+Command+O** and browse its file tree in the sidebar
  (**Command+\\**). Pinned folders are restored when the app opens.
- Create files and folders, rename them inline, or move them to the macOS Trash
  with confirmation. Open tabs, recent files, and navigation follow path changes.
- Open notes quickly with **Command+P**, navigate back and forward with
  **Command+[** and **Command+]**, and follow the breadcrumb bar.
- Search the current folder with **Shift+Command+F**. Search respects `.gitignore`
  and includes the current content of open notes with unsaved changes.
- Add and remove front-matter tags without replacing other YAML fields or
  comments. Parent tags include their subtags, and multiple selected tags narrow
  results to notes containing all of them.
- Search and tag suggestions follow the folder shown in the Files tree. Notes
  with unsaved changes are preserved when another note is opened.

Selecting a folder grants Bioscratch access to its subtree. Folder operations
refuse to rename or trash a granted root.

## Editing and window behavior

- The toolbar Export menu now appears below the toolbar and offers the existing
  HTML and native PDF exports.
- Closing a window or quitting brings each unsaved document forward with
  **Save**, **Delete**, and **Cancel** choices. Cancel keeps the app open.
- **Command+1** through **Command+8** select a numbered tab;
  **Command+9** selects the last tab.
- Documentation now reflects native PDF rendering, the test suite, the separate
  VS Code editor, and the current release process.
- Updated editor and build dependencies include security fixes.

## VS Code extension

The extension remains a Markdown custom editor inside VS Code and receives the
dependency refresh in this release. Folder browsing and the new desktop
navigation shortcuts are macOS app features.

## Continuous validation

The CI workflow runs frontend regression tests, production and Quick Look
preview builds, front-matter fixture round trips, macOS Rust backend tests, and
the VS Code extension typecheck and production build. Release metadata is
checked for consistent versions.
